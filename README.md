Andrei Dan — Personal Portfolio Website

This repository contains the source code for my personal portfolio website:
👉 https://www.andreidan.ca

✨ About the Website

A minimal, three-page portfolio covering:
	•	Home — a short introduction, bio, and how to reach me
	•	Work — what's new (recent roles, certifications, milestones) and selected projects
	•	Archive — fun facts about me

Design

- Single-column, whitespace-driven layout — no cards, no color blocks
- Old-newspaper look: warm paper-white background, one serif typeface (EB Garamond)
- Subtle fade-in-on-scroll only; no parallax or scroll-scrubbed animation

Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Vercel Analytics
